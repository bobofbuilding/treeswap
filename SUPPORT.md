# Support

TreeSwap is currently an unfunded prototype. Use GitHub Issues for non-sensitive product and test feedback. Use the repository Security page for vulnerabilities.

There is no live bridge support desk, recovery service, insurance fund, or guaranteed reimbursement. Do not post wallet secrets, invoices, preimages, account data, or credentials. Direct wallet sends are outside the bridge and cannot be reversed by TreeSwap.

A funded public-testnet release must publish an exact signed adoption policy naming its support owner, incident commander, public support/security/status paths, response objectives, loss allocation, and validity window. If that policy and its real operating evidence are absent or expired, funding must remain closed.
