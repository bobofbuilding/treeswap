# Security policy

TreeSwap is an unaudited prototype and is not ready for real funds. Do not send bridge inventory or rely on the preview as a funded service.

Report a vulnerability through GitHub's private vulnerability reporting flow on the repository Security page. Please include the affected commit, component, impact, reproduction steps, and any suggested mitigation. Do not include private keys, wallet seeds, macaroons, invoices, preimages, personal data, or live credentials.

Public issues are suitable for non-sensitive bugs. Do not publish an exploitable vulnerability before maintainers have had a reasonable opportunity to investigate and coordinate a fix.

During a future funded public-testnet window, only the support owner and incident commander named in the exact signed adoption policy may make operational commitments. Repository maintainers, test fixtures, and this document do not authorize funding or promise production response coverage.
